# Bad Apple!! for Yandex Station 2
Мой скрипт на анимацию Bad Apple!! на Яндекс Станции 2 LED подсветки
## 1. Как работает
1. Скрипт сначала загружает нужные значения из frames.txt
2. Запускает звук
3. Рисует кадры в `/dev/fb0` (в сам LED)
как-то так
## 2. Требования
- Яндекс Станция 2 (логично)
- python3, который установлен на станции (yse install python3)
- ну и всё

надо просто написать
```
python main.py
```
ну и всё будет работать
