# nexusnet for Yandex Station 2

My script for the Bad Apple!! animation on the Yandex Station 2 LED lights

## 1. How it works
1. Loads the required values from `frames.txt`
2. Starts the audio
3. Draws the frames to `/dev/fb0` (the LED lights)

yeah thats basically it

## 2. Requirements
- Yandex Station 2 (obviously)
- python3 installed on the station (`yse install python3`)
- thats it

just run

```bash
python main.py
```
and it should work
